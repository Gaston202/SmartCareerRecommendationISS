## 🏗️ Architecture Highlights

### 1. **AI Orchestration Layer**
- Single point for all AI interactions
- **Prompt registry** with Handlebars templates
- **Multi-model failover** (OpenRouter: arcee-ai + stepfun)
- **Strict JSON validation** with Zod schemas
- **Smart caching** (24h TTL for quiz results, 1h for questions)
- **Fallback logic** → deterministic if AI fails

### 2. **Stateful Quiz System**
- **10-question adaptive flow** (not 5!)
- Session stored in **Supabase** (`quiz_sessions`, `quiz_answers`)
- Each answer saved immediately
- Next question generated by AI OR fallback static bank
- On Q10 → automatic career recommendation trigger
- **Cache:** Session state (1h), results (24h)

### 3. **Hybrid Career Recommendations**
- **Deterministic scoring engine:**
  - Skill overlap (40%)
  - Interest matching (30%)
  - Quiz traits (30%)
- Matched against `careers` reference table (seeded with 5 sample careers)
- **AI enhancement:** Personalized explanations for each match
- Results stored in `career_match_results` (top 5 only)

### 4. **CV Analysis - Async Pipeline**
```
Upload PDF → Storage → BullMQ Job → Extract Text → AI Analysis → ATS Score → Suggestions → Store → Complete
```
- Status tracking in `cv_analyses` table (`pending` → `processing` → `completed/failed`)
- Frontend polling supported via `async_jobs` table
- **Predictive scoring:** keyword density + `extracted_data` structure
- **AI suggestions:** ATS issues + improvement tips

### 5. **Roadmap Generator - RAG**
- **Retrieve:** Career roadmap templates from `career_roadmaps`
- **Augment:** User profile (skills, quiz results, CV summary)
- **Generate:** AI personalizes milestones (duration, tasks, resources)
- **Cache:** Personalized per user (12h TTL)

### 6. **Scalability Features**
- ✅ **Redis** for distributed caching (cache-aside pattern)
- ✅ **BullMQ** for async job processing with retries
- ✅ **Row Level Security** on all user tables
- ✅ **Structured logging** (Pino)
- ✅ **Request validation** (class-validator)
- ✅ **Error handling** global filter
- ✅ **Swagger docs** for development
- ✅ **Docker compose** for local dev stack
- ✅ **Production-ready** Dockerfile

## 📈 Scaling Roadmap

**Phase 1 (Current - 1k users)**
- Single NestJS instance
- Supabase + Redis
- Single worker process

**Phase 2 (1k - 10k users)**
- Add load balancer + 2-3 API instances
- Separate worker service (CVRoadmapWorker, AiWorker)
- Add API rate limiting
- Implement request ID tracing

**Phase 3 (10k - 100k users)**
- Scale workers horizontally
- Add database read replicas
- Implement Redis Cluster if needed
- Add CDN for static assets
- Implement feature flags for A/B testing

**Phase 4 (100k+ users)**
- Separate microservices by bounded context (Quiz, Career, CV, Roadmap)
- Migrate to gRPC for internal service communication
- Implement circuit breakers for AI calls
- Add distributed tracing (Jaeger)
- Implement advanced caching strategies (CDN, edge)
